To-Do App Design Requirements (C++)
===================================

1. Core Task Management (CRUD)
------------------------------
* Create: Add a new task with a description.
* Read: View lists of tasks.
* Update: Edit task text, mark as complete/incomplete.
* Delete: Remove or archive a task permanently.

2. Time & Scheduling
--------------------
* Due Dates: Assign deadlines to tasks.
* Calendar View: Display tasks ordered chronologically by day/week/month.
* Recurring Tasks: Auto-reset tasks on a schedule (daily, weekly, etc.).

3. Organization & Metadata
--------------------------
* Tagging: Assign labels (e.g., #work, #personal) to group tasks.
* Priority Levels: Tiered system (High, Medium, Low) for urgency.
* Filtering & Searching: Query tasks by tag, due date, priority, or keyword.

4. Data Persistence
-------------------
* Save/Load: Automatically write task data to a local file (e.g., JSON or CSV) on exit and load on startup.

5. Advanced / Future Features
-----------------------------
* Subtasks: Break down large tasks into smaller, manageable checklist items.
* Undo Action: Revert the last change (e.g., accidental deletion) using a Stack structure.
